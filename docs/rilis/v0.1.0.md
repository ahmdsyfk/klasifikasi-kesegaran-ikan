# v0.1.0 — Pipeline eksperimen (pre-release)

Rilis awal kode penelitian *Perbandingan Efisiensi Arsitektur VGG16, ResNet50, dan InceptionV3
untuk Klasifikasi Tingkat Kesegaran Ikan Berdasarkan Citra Mata pada Perangkat Terbatas*.
Rilis ini berisi **pipeline** saja; model terlatih dan hasil eksperimen menyusul di **v1.0.0**.

## Isi

- **CLI `fishfresh`** — `download → prepare → [roi → prepare] → train → evaluate → benchmark → gradcam → summarize`
- **Pemeriksaan data (proposal 3.5)** — verifikasi berkas, duplikat identik (SHA-256), konflik label,
  pengelompokan hampir-duplikat (pHash) agar tidak bocor antar-bagian; split 70:15:15 terstratifikasi.
  Setiap citra yang dibuang dicatat beserta kriterianya (`data/splits/data_dibuang.csv`).
- **Praproses (3.6)** — RGB, 224×224, `preprocess_input` per arsitektur ditanam di dalam model.
- **Skenario fokus mata** — lokalisasi mata zero-shot (OWLv2), crop persegi + masker lingkaran,
  filter kualitas (mata tak terdeteksi, terlalu kecil, buram, eksposur buruk).
- **Augmentasi (2.7)** — flip, rotasi, perspektif, kecerahan, gamma, noise; hanya data latih;
  catatan parameter dan contoh visual tersimpan per model.
- **Pelatihan** — dua fase (feature extraction → fine-tuning 30 % lapisan atas), early stopping
  (`val_loss`, patience 7), ReduceLROnPlateau, pencatatan waktu pelatihan.
- **Deteksi platform otomatis** — macOS / Windows / Linux / WSL2 dan CPU / CUDA / Metal;
  mixed precision otomatis hanya di GPU CUDA.
- **Evaluasi (3.7)** — accuracy, precision, recall, F1 macro, confusion matrix pada uji MFED dan
  lintas dataset FFE (tanpa pelatihan ulang), selisih F1 sebagai ukuran generalisasi.
- **Efisiensi (3.7.3)** — jumlah parameter, ukuran `.keras`, latensi CPU 4 thread batch 1
  (warm-up 10, 200 citra, 3 ulangan), memori puncak (psutil).
- **Grad-CAM** — visualisasi dan persentase atensi di area mata; uji McNemar antar-arsitektur.

## Dataset (tidak disertakan, unduh dengan `uv run fishfresh download`)

- MFED v2 — DOI 10.17632/67nmx3mhwh.2 (4.800 citra, 3 kelas seimbang)
- FFE v1 — DOI 10.17632/xzyx7pbr3w.1 (4.390 citra, 8 spesies)

## Lingkungan

Python 3.13, TensorFlow 2.21.0, Keras 3.15.1 (kelola dengan `uv`). Lihat README untuk GPU RTX 4060 via WSL2.
